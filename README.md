## ⚡ What is FleetDeck?

FleetDeck is an **open-source alternative to Coolify/Dokploy/CapRover**, re-engineered from the ground up for high reliability, minimal resource consumption (< 25MB RAM), and native AI agent orchestration.

- **Zero-Agent Architecture**: No daemons installed on target nodes. Connects via standard Docker Sockets, SSH keys, or Cloud Sandbox APIs (InstaBox).
- **Hybrid Compute Support**: Manage baremetal homeservers, remote VPS, and ephemeral sandboxes in a single control panel.
- **Dual-Mode Control**:
  - **No-Code Web GUI**: 1-Click Deploy templates (PostgreSQL, Redis, Nginx), live terminal log streaming, resource gauges, and Traefik ingress routing.
  - **AI Agent-Native (Model Context Protocol - MCP)**: Full JSON-RPC 2.0 interface allowing Claude Code, Cursor, and Antigravity agents to inspect, deploy, and restart workloads via natural language.

## 🛠️ Quick Start (1 Minute)

### Option 1: Docker (Recommended)

```bash
docker run -d \
  --name fleetdeck \
  --restart unless-stopped \
  -p 8089:8089 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v $(pwd)/fleet.yaml:/etc/fleetdeck/fleet.yaml:ro \
  -v $(pwd)/data:/data \
  fleetdeck:latest
```

### Option 2: 1-Line Host Script

```bash
curl -sSL https://raw.githubusercontent.com/abibinyun/fleetdeck/main/install.sh | bash
```

## ⚙️ Configuration (`fleet.yaml`)

```yaml
server:
  host: "0.0.0.0"
  port: 8089
  poll_interval_seconds: 300

nodes:
  # 1. Local Node
  - id: "homeserver-local"
    name: "Homeserver Fisik"
    provider: "local_docker"
    docker_access:
      driver: "local_socket"
      target: "/var/run/docker.sock"

  # 2. Remote VPS via SSH Key
  - id: "vps-nat-prod"
    name: "VPS Production"
    provider: "generic_ssh"
    docker_access:
      driver: "ssh"
      target: "your-vps-ip"
      port: 22
      user: "root"

  # 3. Cloud Sandbox (InstaBox)
  - id: "instabox-1"
    name: "InstaBox Node 1"
    provider: "instabox"
    provider_config:
      machine_id: "m_xxxxx"
      api_key: "${INSTABOX_KEY_1}"
      reset_threshold_minutes: "110"
    docker_access:
      driver: "instabox_exec"
      target: "m_xxxxx"
```

## ⌨️ CLI Companion (`fleetctl`)

FleetDeck includes a standalone terminal client `fleetctl` for developers:

```bash
# Build or install fleetctl
go build -o /usr/local/bin/fleetctl cmd/fleetctl/main.go

# Usage
export FLEETDECK_URL="https://fleet.yourdomain.com"
export FLEETDECK_USER="admin"
export FLEETDECK_PASS="your-password"

fleetctl status                            # Cluster telemetry & container metrics
fleetctl apps                              # List deployed applications
fleetctl templates                         # List 1-Click templates (PocketBase, N8N, Postgres, etc.)
fleetctl deploy --name api --node vps-1 --template pocketbase
```

## 🤖 AI Agent Integration (MCP) & Self-Healing

FleetDeck provides a first-class Model Context Protocol (MCP) endpoint at `/mcp` with autonomous diagnostics:

| MCP Tool | Description |
| :--- | :--- |
| `fleet_list_nodes` | Returns all compute nodes, container health, CPU/RAM, and ingress tags. |
| `fleet_deploy_app` | Deploys a new container/template with automatic Traefik router labeling. |
| `fleet_container_action` | Restarts, starts, or stops containers across any node in the cluster. |
| `fleet_diagnose_crash` | Analyzes crash logs, identifies root cause (OOM, port conflict, missing env), and returns suggested fix. |

Configure in your LLM tool client:
```json
{
  "mcpServers": {
    "fleetdeck": {
      "url": "https://fleet.yourdomain.com/mcp"
    }
  }
}
```

## 🏗️ Architecture & Best Practices

- **Go 1.24+**: Statically compiled binary (single executable, zero CGO dependencies).
- **Tailwind + Alpine.js**: Embedded inside binary via `go:embed`. Zero frontend build steps required at runtime.
- **Fail-Safe SSH Transport**: Isolated `-F /dev/null` execution with strict host isolation avoiding UID privilege conflicts.
- **Robust TSV Parsing**: Tolerant to complex regexes and escape characters generated by ingress routers.
